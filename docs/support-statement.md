# Mobile, Browser, and Printing Support Statement

Official pilot release support scope for Bite Tech POS (Billz 2.0).

---

## 1. Supported Browsers

- **Desktop**:
  - Google Chrome (latest 2 versions)
  - Mozilla Firefox (latest 2 versions)
  - Microsoft Edge (latest 2 versions)
- **Mobile & Tablet**:
  - Mobile Chrome (Android 10+)
  - Mobile Safari (iOS 15+)
- **Automated Certification**:
  - Chromium-based browser via Playwright test runner.

---

## 2. Supported Viewports & Usability

The application UI is responsive and certified across the following viewports:

- `390 × 844` — Standard Mobile Portrait (iPhone / Android)
- `412 × 915` — Large Mobile Portrait
- `844 × 390` — Mobile Landscape
- `768 × 1024` — Tablet Portrait
- `1024 × 768` — Tablet Landscape
- `1366 × 768` — Standard 14-inch Laptop (Cashier Terminal)

---

## 3. Printing Support Statement

- **Thermal Bill Printing**:
  - Thermal bill and receipt printing is **supported and certified from the cashier laptop** (1366×768 desktop browser) connected to standard thermal receipt printers (80mm / 58mm).
- **Mobile Thermal Printing**:
  - Thermal printing directly from mobile phones or tablet Bluetooth/Wi-Fi printers is **not certified** for this pilot release. Mobile devices are supported for management, stock inventory, purchasing, reports, and ordering.
