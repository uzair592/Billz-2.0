Create subscription plan

        
        
        
        

          
          
        

        
        

          Each active login session counts as a device; tabs sharing that
          session use one slot. Lowering a limit keeps the most recently used
          sessions and signs out the excess.
        

        

          
        

      

    
    
      

        
Manage owner credentials

        

        
        
        
        
        

          The owner can sign in with their username or login email. All owner
          sessions are revoked when credentials change.
        

        

          
        

      

    
    
      

        
Assign plan / renew subscription

        
        
        
        
        

          Renewal starts at the later of now or the existing expiry. This is an
          audited access adjustment; record payments separately. An
          administrative suspension stays in place.
